# Course Specs

Course specs define the course ID, assessment ID, anonymous student ID pattern,
input modes, question IDs, max scores, and score increments used by prompt
packets.

Status conventions:

- `pilot_rubric_available`: enough rubric structure exists to build prompt
  packets for a pilot or rerun.
- `draft_needs_rubric_extraction`: the file is a planning placeholder only.
  Extract real question IDs, max scores, and rubric details before model calls.

These files must not contain raw student names or identity maps.
