## English

### Frozen scope

This is not a complete 130-point Week 3 experiment. The available combined
scan has 46 pages. Read-only visual audit and course-owner confirmation show
23 students' Page 1 and Page 3 fragments; Page 2 is absent.

The partial benchmark is therefore exactly six questions worth 70 points:

| In scope | Points | Input page |
| --- | ---: | --- |
| Q1?Q4 | 5 each | Page 1 |
| Q9 | 25 | Page 3 |
| Q10 | 25 | Page 3 |

Q5?Q8 are excluded from gold, transcripts, packets, predictions, and metrics.
Any result must be described as a **70-point partial Week 3 benchmark**, never
as full Week 3 accuracy.

### Why this instance is still useful

- The scan is image-only, so every transcript needs OCR/model transcription
  plus human per-question review.
- Raw pages visibly contain names, student IDs, totals, sub-scores,
  ticks/crosses, and comments. Direct multimodal grading on raw pages would
  leak both identity and gold evidence.
- Q1?Q4 provide low-ambiguity calibration; Q9 CFG-to-PDA construction and Q10
  conceptual reasoning include diagrams, epsilon notation, stack symbols, and
  handwriting that make a matched transcript-versus-direct-multimodal comparison
  meaningful.

### Non-negotiable gates

Before any model call:

1. Pair Page 1 and Page 3 privately using original identity fields, then keep
   only S### identifiers.
2. Render anonymous PNG/PDF inputs and obtain human privacy, blind-scoring, and
   answer-content-preservation approval for every page.
3. Freeze development/held-out assignment before seeing model output.
4. Create and review a six-question rubric and private per-question gold table.
5. Build matched reviewed-transcript and direct-multimodal inputs from the same
   anonymous students/pages.

The preparation tool deliberately leaves model_run_allowed=false; record
validation is not a substitute for visual human review.

### Tracked artifacts

- preparation-contract.json: machine-readable scope, source anchors, risks,
  input arms, and blocked gates.
- private-page-layout.schema.json: public schema for the ignored private
  anonymous page layout.
- experiments/course_specs/DSAA3071_week3_partial_pages_1_and_3.json:
  the exact six-question, 70-point course contract.

No raw PDF, student answer, identity map, gold row, anonymized image, or model
output is tracked here.
