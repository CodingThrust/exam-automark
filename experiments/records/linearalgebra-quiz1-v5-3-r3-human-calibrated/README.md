# Linear Algebra Quiz 1 — V5.3-r3 human-calibrated candidate

This public record preserves a new V5.3-r3 rubric after course-owner
calibration. It does not revise the frozen V5.3-r2 draft.

Key r3 changes are explicit final-answer allocations, error-depth-sensitive
calculation criteria, acceptance of valid equivalent symbolic expressions, a
Q3 fundamental-method scoring gate, independent bonus handling, and a strict
deduction-trace contract. The generic skill now distinguishes independent final
answer points from protected downstream process credit.

The record is development-only and has no private gold revision, prompt packet,
model call, metric, or heldout access. All individual work, identities,
transcripts, gold rows, traces, and raw outputs remain private.
