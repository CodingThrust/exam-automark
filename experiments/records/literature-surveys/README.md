# Literature Surveys

This directory stores research-background survey reports for exam-automark.
The reports are written as reproducible background material only: no raw student
data is stored here, no model calls were run, and no files under `Data/` were
read or modified.

## sci-brain workflow note

The requested reference workflow was the sci-brain survey pipeline:

1. `/survey`: search the literature with multiple strategies, consolidate
   directions, and add verified BibTeX to a project knowledge base.
2. `/download-ref`: fetch paper PDFs and render full text into `.knowledge/`.
3. `/survey-writer`: write a structured review from the collected knowledge
   base.

On 2026-07-19, `sci-brain` was installed from
`https://github.com/QuantumBFS/sci-brain` into the local Codex skills area and
the pipeline was run against this repository.

No arXiv, Semantic Scholar, CrossRef, paper-search, or Sci-Hub MCP server was
available in this Codex session, so `/survey` used WebSearch-style discovery and
visible arXiv IDs. The installed sci-brain `download-ref` helpers then populated
the project KB at:

```text
.knowledge/
```

Run outputs:

- `.knowledge/references.bib`: 32 verified arXiv/Semantic Scholar BibTeX
  entries.
- `.knowledge/NOTES.md`: curated survey landscape, open problems, and
  bottlenecks with cite keys.
- `.knowledge/INDEX.md`: regenerated by sci-brain `index.py`.
- `.knowledge/.raw/`: local metadata and PDF cache for 32 arXiv papers.
- `.knowledge/*.md`: local rendered paper markdown for 32 papers.

The raw PDFs, figures, and rendered full-text paper markdown are intentionally
ignored by Git to avoid storing large or copyrighted source material in this
public tool repository. The two committed PDF reports are the reusable research
background artifacts.

Items whose bibliographic details were not fully verified, such as historical
non-arXiv Page/PEG context, remain marked `needs verification` in the report.
